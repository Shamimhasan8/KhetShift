# Final readiness: কী তৈরি, কী এখনো বাকি

## তৈরি ও যাচাই করা

- Working static prototype source, original NASA archive, source manifest এবং retrieval script।
- চারটি জায়গায় 2,192 দৈনিক record করে 8,768 point-days; দুইটি parameter।
- চার জায়গা × বারো রোপণমাস × তিন crop example × পাঁচ sowing year-এর complete input coverage।
- নভেম্বর থেকে পরের বছরের মার্চের window, independent rain sum, irrigation sensitivity, missing-data rejection ও invalid inputs পরীক্ষা pass।
- Crop-water ranges মূল FAO source-এ মিলিয়ে দেখা হয়েছে।
- বাংলা project description, English project-page draft, technical README, video storyboard, pitch materials।
- কোনো ML training, farmer trial, yield accuracy, measured water savings বা NASA endorsement-এর দাবি নেই।

## স্থানীয় submission-এর আগে অবশ্যই

1. **Rule fit:** organiser-এর exact form, deadline/timezone, accepted challenge, pre-built/AI assistance policy, video length/file limits ও language requirement নিশ্চিত করুন। যোগাযোগের draft নিচে। Current local full 2026 rulebook যাচাই করা যায়নি।
2. **Links:** website সবার জন্য খুলে দিন বা public hosting-এ source deploy করুন। প্রথম Sites version private; owner ছাড়া judges খুলতে পারবেন না। Incognito-তে website, GitHub ও video তিনটি খুলুন।
3. **GitHub:** নতুন source আপনার repository-তে publish করুন। Connector-এ বর্তমান repository push permission নেই, তাই existing repo পরিবর্তন বা remote GitHub publication সম্পন্ন করা হয়নি। ZIP-এ source ready। Original TerraPulse development history মুছবেন না।
4. **Identity:** registered team name, members, local event ও বাস্তব contribution যোগ করুন। বানানো teammate বা feedback লিখবেন না।
5. **Video:** packaged presentation preview final live demo নয়। VIDEO_BN.md অনুযায়ী ৯০–১২০ সেকেন্ড screen recording ও Bangla voice দিন; local limit অনুযায়ী কাটুন।
6. **Device check:** laptop ও phone-এ চার জায়গা, planting-month click, water slider, invalid number, retry, detail selector, export ও data-source links পরীক্ষা করুন। Cloud browser UI/device testing এই static build-এর জন্য সম্পন্ন হয়নি।
7. **Save proof:** final form জমা হলে confirmation page/ID, timestamp, submitted links এবং exact file versions সংরক্ষণ করুন। এই কাজের সময় contest form submit করা হয়নি।
